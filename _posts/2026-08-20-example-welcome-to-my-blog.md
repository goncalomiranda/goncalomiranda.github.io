> **Note:** This is an example post included to demonstrate the blog system on this site. Feel free to edit or delete it once you publish your own content.

Welcome! This post exists to show how the blog on this site works end to end: it is a
plain Markdown file stored in `_posts/`, rendered with the shared post layout, and
listed automatically on the [blog index](/blog/).

## What this example demonstrates

- Writing posts in Markdown with front matter (title, description, tags).
- Automatic listing on `/blog/`, newest posts first.
- Shared header, navigation, and footer styling reused from the homepage.
- SEO metadata (canonical URL, Open Graph, Twitter cards) generated per post.
- An RSS feed available at [`/feed.xml`](/feed.xml).

## How publishing works

1. Add a new file to `_posts/` named `YYYY-MM-DD-your-post-slug.md`.
2. Add front matter with at least a `title`, and optionally `description` and `tags`.
3. Write the body in Markdown.
4. Commit and push to `main` — the site rebuilds and deploys automatically.

That's it — no database, CMS, or server required. Everything here is a static file
built by Jekyll and hosted on GitHub Pages.
